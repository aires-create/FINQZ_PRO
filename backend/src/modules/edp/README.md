# EDP Runtime Foundation

Runtime foundation for the Enterprise Decision Platform.

## Scope
- Domain module structure for the approved EDP baseline.
- Contract and envelope materialization only.
- No business rules, no external integrations, no financial computation.

## Layers
- `domain`
- `application`
- `infrastructure`
- `presentation`
- `contracts`
- `validators`
- `repository`
- `service`
- `routes`
- `tests`
